# News-analytics-for-business-decision-making-AlphaBank-2026
## 🛠️ Быстрый запуск бэкенда для Frontend-разработки

Инструкция для локального развертывания сервера и наполнения базы данных реальными КИБ-данными хакатона.

### Шаг 1. Переменные окружения
В папке `backend/` скопируйте файл конфигурации из примера (все доступы к локальной БД уже настроены по умолчанию):
```bash
cp backend/.env.example backend/.env
```

### Шаг 2. Запуск инфраструктуры (СУБД + API)
Для работы эндпоинтов необходимо запустить PostgreSQL в Docker и сам сервер FastAPI. Откройте два окна терминала:

*   **Терминал 1 (Запуск базы данных из корня проекта):**
    ```bash
    docker compose up -d
    ```
*   **Терминал 2 (Запуск сервера FastAPI из папки backend):**
    ```bash
    cd backend
    source .venv/bin/activate  # Для Linux/macOS
    # На Windows: .venv\Scripts\activate
    uvicorn main:app --reload
    ```
> 🔗 **Проверка:** После этого интерактивная документация API со всеми схемами контрактов станет доступна по адресу: **`http://127.0.0`**.

### Шаг 3. Загрузка реальных КИБ-данных в БД (Выполняется 1 раз)
Чтобы эндпоинты возвращали не пустые массивы, а реальный граф связей бизнеса Альфа-Банка, запустите асинхронный пайплайн импорта. 

Убедитесь, что исходные файлы `df_Uid_data_hack.csv`, `df_Fid_Uid_link_hack.csv` и `df_Uid_payment_hack.csv` лежат в папке `backend/data/`, и запустите скрипт из папки `backend`:
```bash
python scripts/etl_import.py
```
*Скрипт автоматически нормализует заголовки, дедуплицирует грязные строки и загрузит ~480 000 записей в PostgreSQL за 1.5 минуты.*

1. **Инсайт (Валидированный Mock + Текст аналитики под вёрстку):**
